# Souls Gaming Community Website

A free static website for Souls Gaming, designed for GitHub Pages.

## Publish on GitHub Pages
1. Create a public GitHub repository named `souls-gaming`.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub Pages will provide your website address.

The Discord, YouTube, and Twitch buttons are already connected.
